# Sprint 17.0

Base: Sprint 16.3 limpio.

Cambios:
- El botón Meter resultado no aparece en partidas confirmadas.
- Las partidas confirmadas no se pueden editar desde Jornadas.
- Si se borran las vacas/resultados en Excel, la partida vuelve a Pendiente aunque la columna status siga en confirmed.
- Una partida solo puede considerarse confirmada si tiene resultado válido y completo.
- La auto-confirmación 24h solo aplica a resultados válidos y completos.
- Estadísticas/parejas ignoran partidas no confirmadas.

No se toca Sedes, Hall of Fame ni Jugadores.
